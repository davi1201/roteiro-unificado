## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Formulário React → supabase.functions.invoke | Input do admin (userId + password) enviado à Edge Function via anon client |
| Formulário React → supabase.auth.signInWithPassword | Senha atual do usuário enviada ao GoTrue para re-autenticação |
| Formulário React → supabase.auth.updateUser | Nova senha enviada ao GoTrue com JWT do usuário logado |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05 | Spoofing | ChangePasswordModal — verificação de senha atual | mitigate | Opção B implementada: signInWithPassword verifica senha atual antes de updateUser; garante que o usuário logado conhece a senha atual antes de alterá-la |
| T-13-06 | Tampering | ResetPasswordModal — fechar modal antes de mutation | mitigate | onClose() apenas em onSuccess; usuário não pode fechar acidentalmente pensando que foi bem-sucedido quando não foi |
| T-13-07 | Information Disclosure | ResetPasswordModal — memberEmail em DialogDescription | accept | Email do membro é exibido ao admin que já tem acesso à listagem de membros da org; sem vazamento adicional |
| T-13-08 | Denial of Service | ChangePasswordModal — múltiplos submits durante isPending | mitigate | Button type="submit" desabilitado via isLoading={mutation.isPending}; impede duplo-submit |
