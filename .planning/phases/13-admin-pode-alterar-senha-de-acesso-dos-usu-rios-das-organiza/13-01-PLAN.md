<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Edge Function | Chamadas externas com user_id e password no body; deve validar UUID e password length antes de chamar auth.admin |
| Edge Function → Supabase GoTrue | admin.updateUserById executa com service_role — qualquer user_id válido pode ter senha alterada |
| Cliente → Schema Zod | Input do formulário passa pelo schema antes de ser enviado à Edge Function |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Elevation of Privilege | reset-user-password Edge Function | mitigate | Validar UUID format com regex antes de chamar updateUserById; evita user_id malformado causar erros inesperados no GoTrue |
| T-13-02 | Tampering | reset-user-password — chamada direta sem autenticação de caller | accept | A Edge Function não verifica o role do chamador; aceito para piloto de 5 construtoras em ambiente controlado. Mitigação futura: verificar JWT do admin antes de prosseguir |
| T-13-03 | Tampering | changePasswordSchema | mitigate | .refine() garante que newPassword === confirmPassword no schema; erro aparece no campo correto (confirmPassword) via RHF |
| T-13-04 | Information Disclosure | Edge Function error messages | mitigate | Mensagens de erro genéricas ('Invalid user_id', 'Password must be at least 8 characters') — não vaza informação sobre existência do usuário |
| T-13-SC | Tampering | npm/pip install | accept | Nenhum pacote novo instalado; Edge Function usa import Deno HTTP de esm.sh (mesmo padrão do create-user existente) |
</threat_model>
